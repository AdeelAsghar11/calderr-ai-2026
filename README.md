## ⚡ Quick Start & Setup

### Prerequisites
* **Python:** 3.11+
* **Package Manager:** `uv` (recommended) or `pip`
* **API Key:** Groq API Key (`GROQ_API_KEY`)

### Setup Instructions

1. **Clone the repository:**
   ```bash
   git clone git@github.com:AdeelAsghar11/calderr-ai-2026.git
   cd calderr-ai-2026
   ```

2. **Set up virtual environment & install dependencies:**
   ```bash
   # Using uv (recommended)
   uv venv
   uv sync

   # Or using pip
   python -m venv .venv
   source .venv/bin/activate  # On Windows: .venv\Scripts\activate
   pip install -r requirements.txt
   ```

3. **Configure Environment Variables:**
   Create a `.env` file in the repository root:
   ```env
   GROQ_API_KEY=your_groq_api_key_here
   ```

### Running Individual Projects

* **Project 1-I-A (CLI Assistant):**
  ```bash
  uv run python projects/project-1-ia/chatbot.py
  ```

* **Project 1-P-C (Research Assistant UI):**
  ```bash
  uv run streamlit run projects/project-1-pc/research_assistant.py
  ```

* **Project 3-P-B (Research Engine UI):**
  ```bash
  uv run streamlit run projects/project-3-pb-research-engine/app.py
  ```

* **Project 4-P-C (Workflow Platform Dashboard):**
  ```bash
  uv run streamlit run projects/project-4-pc-workflow-platform/src/dashboard.py
  ```

* **Project 5-P-B (SWE Platform Dashboard):**
  ```bash
  uv run streamlit run projects/project-5-pb-swe-platform/src/dashboard.py
  ```

* **Project 6-P-B (GraphRAG Intelligence Dashboard):**
  ```bash
  uv run streamlit run projects/project-6-pb-graphrag-intelligence/dashboard.py
  ```
